## Disclosure Statement

Defensive security maintenance, process-isolation auditing, and vulnerability research on this open-source deterministic routing library are actively conducted under strict verification protocols, leveraging authorized cybersecurity clearance within the OpenAI Daybreak program.

## Security Scope

Security review covers:

- Execution-boundary enforcement and unauthorized code execution.
- Process isolation and privilege separation.
- Routing integrity and JSON schema validation.
- Malformed inputs, unexpected state transitions, and boundary bypasses.

Testing must remain within systems and environments for which the
researcher has explicit authorization.

## Vulnerability Reporting

Use GitHub's private vulnerability reporting feature when enabled.
Otherwise, request a private reporting channel from the Lead Security
Maintainer before sharing sensitive details.

Include:

- Affected commit or release.
- Environment and configuration.
- Reproduction steps and a minimal proof of concept.
- Expected and observed behavior.
- Security impact and proposed mitigation, if available.

Keep credentials, personal data, and exploit details out of public
issues.

## Verification Protocol

Security changes require a reproducible finding, documented impact,
maintainer review, and verification that the mitigation addresses the
reported failure.

Verification records should identify the tested commit, configuration,
test procedure, results, and remaining limitations.

## Supported Versions

Security support applies to releases explicitly designated as supported
by the Lead Security Maintainer.
